## 2. Framework and dependencies (verified)

- Main site: Next.js 16.3.4, React 19.2.6, TypeScript 5.9.3.
  - Static export: `next.config.ts` sets `output: "export"`, `trailingSlash: true`, `images: { unoptimized: true }`.
  - There's no server at runtime. Everything ships as static HTML/CSS/JS.
- Runtime dependencies: `react`, `react-dom`, `next`, `lucide-react` (UI icons only, no brand logos).
- Dev dependencies: `typescript`, `oxlint`, `oxfmt`, `opentype.js` (signature build), type packages.
- **No animation library in the main site.** All motion is plain CSS keyframes and transitions, plus the Web Animations API in `scroll-reveal.tsx`.
- No Tailwind. Plain CSS with design tokens on `:root` in `app/globals.css`.
- Fonts: body uses `Arial, Helvetica, sans-serif`. Labels use `ui-monospace`. No web fonts load on the main site.
  - The README says "Fonts are loaded from external services". That's only true for the Vite sub-app, which imports Inter from Google Fonts.
- Sub-app `apps/portfolio-2/`: React 18, Framer Motion 11, Vite 5. It's built separately and served at `/projects/shopify-technical-studies/`.
- `package.json` asks for Node `>=22.13.0`. CI uses Node 22.

## 3. Build and deploy (verified)

- `npm ci` runs `postinstall`, which builds the signature and installs the sub-app's dependencies.
- `npm run dev` builds the sub-app first, then runs `next dev`.
- `npm run build` runs these steps in order:
  1. Build the signature.
  2. Build the sub-app.
  3. Run `next build --webpack`.
  4. Run `scripts/finalize-static.mjs`.
- Output goes to `out/`. `npm start` serves `out/` at `http://127.0.0.1:4173`.
- Deploy: `.github/workflows/deploy-pages.yml` runs **only on push to `main`**, or when started by hand. It lints, builds, typechecks and deploys `out/` to GitHub Pages.
  - Pushing a feature branch does not deploy.
- Baseline on 2026-10-22 (on `portfolio-refresh` = this branch's base):
  - `npm run lint`, `npm run typecheck` and `npm run build` all passed.
  - This was run locally on Node 20.19.6. CI uses Node 22.

## 5. Existing styling and motion (verified)

- Colours (`app/globals.css` `:root`):
  - Background `#101411` (near-black, green tint).
  - Text `#f0f2e9`.
  - Accent lime `#c4f36b`.
  - Border `#343d35`.
  - Card `#171d18`.
  - Dark only (`color-scheme: dark`).
- Motion tokens: `--ease-out: cubic-bezier(0.16, 1, 0.3, 1)` and `--duration-fast/base/slow` (0.2s / 0.45s / 0.7s).
- Hero entrance: the `hero-in` keyframes, only inside `@media (prefers-reduced-motion: no-preference)`.
- Signature: each letter's outline draws in, the fill fades in, then the outline fades out. Delays come from `--stagger`.
- `ScrollReveal` (`app/scroll-reveal.tsx`):
  - Content is always visible in CSS. JS only adds an entrance animation when the element scrolls into view.
  - It respects reduced motion, cancels animations on keyboard focus, and skips nested `[data-reveal]` elements.
  - **This is a good base for the new section entrances.**
- `stagger(index)` (`app/stagger.ts`) gives per-item delays (capped at 3 steps × 70 ms in `ScrollReveal`).
- A global `prefers-reduced-motion: reduce` block makes all animations and transitions near-instant.
- Breakpoints in use: 1000px, 900px, 680px.
- Header: sticky, shrinks and blurs after 8px of scroll (rAF-throttled scroll listener).

## 10. Assessment: strengths and weaknesses (opinion)

Strengths:

- Strong, honest content: real experience numbers, scoped project notes and clear availability.
- Fast and simple: static export, no animation library, almost no client JS.
- Accessibility basics are done well: skip link, `sr-only` name for the SVG heading, focus styles, reduced-motion handling, content visible without JS.
- Content is data-driven (`profile.ts`, `projects.ts`), so a redesign can change the presentation without rewriting copy.

Weaknesses and opportunities:

- No photo. The hero is all type, so there's no personal visual anchor.
- Skills are a text list. It's the least visual section, and it's low on the page (section 03).
- One accent colour (lime). The requested purple look needs a palette decision.
- The hero's right column is a short paragraph. There's room for a visual object.
- Header nav has Experience, Projects and Contact only. No Skills or About links.
- The body font is Arial. The design could use a stronger typeface (the untracked Geist files hint at this).
- Small: the README's font sentence is out of date. `globals.css` has some one-line media query blocks that are hard to read.
