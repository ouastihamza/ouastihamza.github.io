# Shopify Technical Studies integration

Original React 18 / TypeScript / Framer Motion / Vite application, retained as a standalone static sub-app. The parent build runs this Vite build first, then copies its HTML into the exported `/projects/shopify-technical-studies/` directory. Assets use `/portfolio-2-assets/` from the domain root. No Shopify credentials, live store, iframe, Node backend or environment variables are required.

All six original sections are retained. The public name is Shopify Technical Studies. Depicted store data and shopping controls are illustrations; navigation, scroll stories and view tabs are interactive. The parent README documents build and deployment.
